# ML-Student-Performance-Prediction-and-Model-Evaluation-
This project focuses on developing a complete machine learning workflow using the Student Performance dataset to understand and predict student exam performance. The analysis begins with Exploratory Data Analysis (EDA) to inspect the dataset, identify numerical and categorical variables, examine distributions, relationships, correlations, missing values, potential outliers, and determine the factors that appear to be associated with exam_score. The dataset is then prepared for machine learning through appropriate feature selection and preprocessing, with exam_score used as the target variable for a regression problem. A Linear Regression model is trained using relevant student-related features such as study hours, attendance, sleep hours, social media usage, Netflix usage, exercise frequency, mental health rating, and other suitable variables. The regression model is used to generate predictions and is evaluated using appropriate regression metrics. In addition, a classification problem is created by converting exam_score into Pass and Fail categories using 50 marks as the passing threshold. An appropriate classification model is trained and evaluated using a confusion matrix, accuracy, precision, recall, and F1-score. The project also compares training and testing performance to identify possible signs of overfitting or underfitting. Finally, the project summarizes the key EDA and machine learning findings and presents five meaningful insights about the factors influencing student academic performance.
